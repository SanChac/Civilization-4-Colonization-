Для запуска мода необходимо следущее:
1) В папке с документами найдите папку "My Games" в которой будет папка с названием вашей папки с цивой
2) В папку "MODS" закинуть репозиторий(если папки нет то создайте её)
3) В игре во вкладке "Дополнительно" загрузите мод

Первый выпуск мода усложняющий игру и добавляющий несколько интересных механик меняющих геймплей.
Идея мода заключается в том чтобы усложнить игру и добавить больший баланс для того чтобы дать игрокам возможность составления разных тактик со своей философией
